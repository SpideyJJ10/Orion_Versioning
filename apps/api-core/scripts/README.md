# Scripts Directory

This directory contains utility scripts for development and maintenance tasks.

## Available Scripts

### `migrate.py`
Database migration utility script.

### `append_css.py`
Utility script for appending CSS styles to frontend files.

### `append_css2.py`
Enhanced version of CSS appending utility.

### `replace.py`
General purpose find-and-replace utility for code refactoring.

### `replace_js.py`
JavaScript-specific find-and-replace utility.

## Usage

Run scripts from the project root directory:

```bash
python scripts/script_name.py
```

**Note:** These are development utilities and should not be used in production environments.
